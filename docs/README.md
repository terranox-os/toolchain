# Toolchain Documentation

This directory owns the detailed TerranoxOS toolchain bootstrap, sysroot,
triple, container, and validation notes that were originally carried under
`terranox-os/terranox-os/docs/toolchain`.

The main OS repository keeps only consumer-facing notes about how it discovers
and consumes exported toolchain artifacts.
